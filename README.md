# QualityBoard — demo

Espacio documental QA local de Alan Berra Garcia. Un proyecto ficticio por navegador: requisitos, casos, ciclos, defectos y cobertura de diseño. Sin cuentas, adjuntos ni sincronización. Los registros y respaldos permanecen en el dispositivo.

Resolver un defecto no aprueba una prueba. La cobertura mide vínculos de diseño, no calidad. Guarda respaldos; el almacenamiento del navegador puede borrarse. Fuente principal privada. No cargar información personal ni confidencial.
